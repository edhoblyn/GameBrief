# GameBrief — Feature Build Guide

> Last updated: 2026-03-17

## All MVP Features — Status: Built

### 1. Authentication

- Email/password login and signup via Devise
- Google OAuth via OmniAuth (`users/omniauth_callbacks_controller`)
- Profile updates without password re-entry for non-credential changes

### 2. Games

- IGDB import via `IgdbClient` service using Twitch credentials
- Games index with search, genre filter, free-to-play filter, multiplayer filter, and sort (A-Z, most followed)
- Game detail page with follow/unfollow action
- Game detail page shows latest patches and upcoming events
- Active filters can be cleared individually without resetting the full browse state

### 3. Follows / Personal Library

- Follow and unfollow games
- Followed games feed into `My Games`, `My Patches`, `My Events`, and `My Profile`

### 4. Patches

- Patches ingested via 29 automated scrapers (25 active, 4 blocked) plus manual seeding
- Standalone patches index with game filter, date filter, and sort
- Nested patches index under a game
- `published_at` support with freshness badges and date filtering
- Patch detail page with full notes

### 5. AI Patch Summaries

- Three stored summary types: Quick Summary, Casual Impact, Should I Log In?
- Generate and regenerate actions per type on the patch page
- Summaries generated by Claude Opus 4.6 via `SummaryService`

### 6. Patch Presentation

- Scraped notes reformatted into structured AI accordion sections via GPT-4o (`PatchPresentationService`)
- Turbo frame polling shows progress state while generation runs
- Fallback service handles formatting when AI is unavailable

### 7. Patch Chatbot

- One persistent chat per user per patch
- GPT-4o responses via `ruby_llm`
- Full conversation history replayed for context
- Patch content injected into AI instructions
- 5-message user limit per chat
- Real-time SSE streaming

### 8. Events

- Events index with time-range filters (all upcoming, this week, this month, future) and multi-game filter
- Event detail page with status, countdown, AI summary, and Google Calendar link
- 18 automated event importers plus manual seeds for blocked sources
- One-sentence AI event summaries via Claude Opus 4.6

### 9. Reminders

- Create and remove reminders on event pages
- `My Events` page lists saved reminders with empty state

### 10. Social Features

- Friendships: add and remove friends from `Find Friends` page
- User search by username or email
- Posts: create and delete social posts
- Post likes: like and unlike posts (`LikesController`, one like per user per post)
- Individual player profile pages (public — no login required)
- Players index (admin only)

### 11. Profile

- `My Profile` social-style hub with highlights, reminder/patch spotlight cards
- `For You` / `Communities` tabbed feed (presentation layer — some content is still mock)
- Notification toggle UI (stored in localStorage)
- Avatar and cover image uploads via Active Storage
- Username and credential updates via custom Devise registrations controller

### 12. Admin Tools

- Admin dashboard at `/admin/dashboard`
- Manual patch scrape and event import triggers (single source and run-all)
- Cache-based scrape/import log output
- Admin role management (promote by email, remove with last-admin guard)
- Chat history clear action

## Deployment

Deployed to **Heroku** (EU region, app name `gamebrief-eu`).

```bash
heroku run bin/rails db:migrate
heroku run bin/rails db:seed
heroku run bin/rake patches:scrape_all
heroku run bin/rake events:import_all
```

Required Heroku Config Vars:

- `RAILS_MASTER_KEY`
- `GOOGLE_OAUTH_CLIENT_ID`
- `GOOGLE_OAUTH_CLIENT_SECRET`
- `TWITCH_CLIENT_ID`
- `TWITCH_CLIENT_SECRET`
- `OPENAI_API_KEY`
- `ANTHROPIC_API_KEY`
